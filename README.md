# SIS-DIS 2025 - Frontend

En este repositorio se desarrolla la interfaz de usuario (UI) del proyecto **SIS-DIS 2025**. Se enfoca en la capa de presentación y la experiencia del usuario, interactuando con la API del backend.

## Contenido Principal

- **Framework/Librería Principal:** Angular
- **Arquitectura de Componentes:** Organización y flujo de navegación de la UI.
- **Estilos y Diseño:** Lineamientos de diseño, hojas de estilo y componentes de interfaz.
- **Gestión de Estados:** Manejo de datos compartidos mediante Springboot
- **Pruebas de Interfaz (UI Tests):** Validación de la consistencia y usabilidad de cada componente.

## Cómo Contribuir

1. Descarga las dependencias y configura tu entorno de desarrollo local.
2. Participa en la creación o revisión de componentes mediante **pull requests**.
3. Sigue las guías de estilo establecidas (como ESLint, Prettier, etc.) y las convenciones del proyecto.

## Próximos Pasos

Se continuará iterando sobre la interfaz con mejoras en accesibilidad, rendimiento y usabilidad según la retroalimentación de usuarios y requerimientos del cliente.
